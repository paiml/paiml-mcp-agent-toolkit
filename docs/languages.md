# PMAT Language Support

## Supported Languages

PMAT supports multi-language code analysis:

- Rust (full support)
- TypeScript/JavaScript (full support)
- Python (full support)
- Go (full support)
- C/C++ (beta)
- Bash (beta)
- PHP (beta)
- Swift (beta)
- WebAssembly (experimental)
- Kotlin (experimental)
