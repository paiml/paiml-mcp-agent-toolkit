# MCP Polyglot Analysis Tools

## Overview

PMAT's MCP implementation supports multi-language code analysis.

## Tools

- `analyze_code` - Analyze code in any supported language
- `complexity_analysis` - Calculate complexity metrics
- `mutation_testing` - Generate and test mutations
