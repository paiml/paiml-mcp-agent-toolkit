# Quality Gates

## Overview

PMAT enforces quality gates based on Toyota Way principles.

## Quality Checks

- Code complexity limits
- Test coverage thresholds
- Mutation score requirements
- Dead code detection

## Usage

```bash
pmat quality-gate --config quality-gate.toml
```
