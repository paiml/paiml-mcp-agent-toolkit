# Mutation Testing

## Overview

PMAT provides mutation testing for Rust, TypeScript, and Python.

## Usage

```bash
pmat mutate <file>
```

## Supported Mutations

- Arithmetic operators
- Logical operators
- Comparison operators
- Return value mutations
