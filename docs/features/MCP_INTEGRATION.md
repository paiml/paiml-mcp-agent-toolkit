# MCP Integration

## Overview

PMAT implements the Model Context Protocol (MCP) for AI-assisted development.

## Features

- MCP server implementation
- Tool definitions for code analysis
- Integration with Claude and other LLMs

## Usage

Run PMAT as an MCP server:

```bash
pmat mcp-server
```
