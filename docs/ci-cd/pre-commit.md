# Pre-commit Hook Integration

## Overview

PMAT can be integrated into git pre-commit hooks for continuous quality enforcement.

## Installation

Pre-commit hooks are automatically installed on first commit.

## Hooks

- bashrs linting
- pmat-book validation
- Documentation accuracy validation
