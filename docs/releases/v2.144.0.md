# Release Notes: v2.144.0 - Claude Code Sub-Agent Scaffolding

**Release Date**: October 7, 2025
**Sprint**: 24 (Phase 1)
**Focus**: Claude Code Sub-Agent Scaffolding
**Ticket**: PMAT-7007

---

## 🎯 Overview

v2.144.0 introduces comprehensive scaffolding for generating specialized Claude Code sub-agents, enabling AI-powered code quality assistance through PMAT's MCP integration.

This release implements **5 production-ready sub-agents** with CLI tools for generation, validation, and MCP tool mapping.

---

## ✨ New Features

### Claude Code Sub-Agent Scaffolding (PMAT-7007)

**Infrastructure** (`subagents.rs` - 350 lines):
- `PmatSubAgent` enum with 12 agent types (5 MVP, 7 future)
- `SubAgentGenerator` for template rendering and export
- MCP tool mapping system for Claude Code integration
- FromStr parsing for CLI argument handling

**5 MVP Sub-Agent Templates** (~4,200 lines):

1. **Complexity Analyst** - Cyclomatic and cognitive complexity analysis
   - Tools: `pmat__analyze_complexity`, `pmat__analyze_cognitive_complexity`
   - Use case: Identify high-complexity hotspots, suggest refactorings

2. **Mutation Tester** - ML-powered mutation testing specialist
   - Tools: `pmat__mutation_test`, `pmat__mutation_predict`, `pmat__equivalent_detector`
   - Use case: Test quality assessment, equivalent mutant detection

3. **SATD Detector** - Technical debt tracking
   - Tools: `pmat__analyze_satd`, `pmat__analyze_context`
   - Use case: Identify TODO/FIXME/HACK comments, prioritize debt

4. **Dead Code Eliminator** - Safe unused code removal
   - Tools: `pmat__analyze_dead_code`, `pmat__analyze_imports`
   - Use case: Identify safe-to-delete code with confidence scoring

5. **Documentation Enforcer** - Generic description detection
   - Tools: `pmat__check_generic_docs`, `pmat__analyze_context`
   - Use case: Enforce PMAT documentation standards, eliminate vague descriptions

**CLI Commands** (`subagent_handlers.rs` - 400 lines):

```bash
# List available sub-agents
pmat scaffold list-subagents [--all]

# Create specific sub-agent
pmat scaffold create-subagent <name> [-o <dir>]

# Create all MVP sub-agents
pmat scaffold create-all-subagents [-o <dir>]

# Validate sub-agent definition
pmat scaffold validate-subagent <file>

# Show MCP tool mapping
pmat scaffold show-tool-mapping [--agent <name>]

# Export tool mapping as JSON
pmat scaffold export-tool-mapping -o <file>
```

**MCP Tool Mapping**:
- Each sub-agent maps to specific PMAT MCP tools
- Tool prefix: `pmat__`
- JSON export available for automation
