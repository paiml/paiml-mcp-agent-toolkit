# PMAT CLI Reference

## Overview

PMAT provides a comprehensive command-line interface for code analysis.

## Basic Usage

```bash
pmat [SUBCOMMAND] [OPTIONS]
```

## Common Commands

### Context Generation

```bash
pmat context [OPTIONS]
```

### Mutation Testing

```bash
pmat mutate [OPTIONS]
```

### Quality Gates

```bash
pmat quality-gate [OPTIONS]
```

## Getting Help

```bash
pmat --help
pmat <subcommand> --help
```
