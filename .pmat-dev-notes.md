# PMAT Development Notes - IMPORTANT

## Binary Location (DO NOT FORGET!)

**The pmat binary is ALWAYS at: `./target/debug/pmat`**

This is a Rust workspace project, so even though the code is in `server/`, the binary is built to the workspace root's target directory.

### Quick Commands

```bash
# Build
make build  # or cargo build --manifest-path server/Cargo.toml

# Run pmat
./target/debug/pmat [command]

# Test single file analysis
./target/debug/pmat analyze complexity --file server/src/cli/handlers/lint_hotspot_handlers.rs
./target/debug/pmat analyze lint-hotspot --file server/src/some_file.rs
./target/debug/pmat quality-gate --file server/src/some_file.rs

# Run from anywhere in the project
$(git rev-parse --show-toplevel)/target/debug/pmat [command]
```

## Common Mistakes to Avoid

❌ WRONG: `./server/target/debug/pmat`
❌ WRONG: `cd server && ./target/debug/pmat`
❌ WRONG: `server/target/debug/pmat`

✅ CORRECT: `./target/debug/pmat`

## Workspace Structure

```
paiml-mcp-agent-toolkit/
├── Cargo.toml          # Workspace root
├── target/             # All build artifacts go here
│   └── debug/
│       └── pmat        # The binary is HERE!
├── server/
│   ├── Cargo.toml      # Package definition
│   └── src/            # Source code
└── Makefile            # Build commands
```
